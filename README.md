# Ares - Offline Education Library 🚀

Ares is an offline education dashboard built as a responsive HTML/CSS/JavaScript app. It delivers a polished learning experience for users who want to access courses, notes, videos, and progress tracking without an internet connection.

## 🌟 Project Overview

**LearnOffline** is designed to feel like a modern learning dashboard:

- 💻 Offline-ready study interface
- 📚 Course browsing and downloads
- 📈 Progress statistics and completion trackers
- 🎥 Offline video player with resume support
- 🗂️ Bookmarks, notes, and storage management
- 🧭 Intuitive sidebar navigation and search

## ✨ Key Features

- **Dashboard view** with welcome cards and learning statistics
- **Sidebar navigation** for quick access to Dashboard, Courses, Downloads, Videos, Notes, Bookmarks, Progress, and Settings
- **Animated counters** for course progress and quiz completion
- **Storage usage indicator** with visual progress bar
- **Offline indicator** and local storage persistence
- **Responsive UI** styled with `ares-style.css`

## 🚀 Getting Started

1. Open `index.html` in a web browser.
2. The interface loads locally and works without an internet connection.
3. Explore the dashboard, use the sidebar menu, and review offline course details.
